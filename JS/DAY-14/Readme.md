Promises :- 

Promises is a javascript object, it represents the task either it will complete(fullfilled) or failed (reject) in the future. It helps of write asynchronous code.
and we can write the code in simple way.

There are three stages of promises :- 
1. Pending
2. fulfilled 
3. reject 

Mainly we have two methods of promises :- 
1. .then - when task is completed that time , this method will work.
2. .catch - when task is failed  that time , this method will work.
3. .finally - it always run then task is resolved or not.
