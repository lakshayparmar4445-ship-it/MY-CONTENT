Coditional Statement :- 
   If we have multiple condition so that time we can use the conditional statement.

Types :- 
1. if else -> only single condition
2. if elseif else -> multiple condition 
3. switch -> if have multiple cases 

if(condition){
   // statement
}else{
  // statement 
}
========================

if(condition){
    statement 
}else if(condition){
     statement 
}else if(condition){
   statement 
}else{
    statement
}
================================
let num = 1;
switch(num){
    case 1:
     statement 
     break;
     case 2:
      statement
      break;
    default
      statement
      break
