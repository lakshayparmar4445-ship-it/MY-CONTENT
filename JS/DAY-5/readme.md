Loops :- when we want to perform the task repeatly that time we can use the loop.

Mainly we have diff types of loop :- 
1. for loop 
2. while loop
3. do while loop

Diff b/w for loop and while loop.
1. when number of iterations is known.
2. when number of iteration is unknown.

2. In for loop init , condition and incre/decre in the single line.
3. In while loop init , condition and incre/decre in the diff diff line.

3. Syntax :- 
for(init;condition;incre/decre){
    // statement 
}

3. Syntax :- 
init 
while(condition){
    // statement 
    incre/decre;
}

===================================

Diff b/w while loop and do while loop.
1. While loop is an entry control loop.
2. do while is an exit control loop.

2. while loop execute based on the condition , when condition is true it will execute.
3. do while run atleast once.

3. Syntax :- 
init 
while(condition){
    // statement 
    incre/decre;
}

3. Syntax :- 
init
do{
    // statement 
    incre/decre
}while(condition)
