Axios :- 

Axios is a promise-based HTTP client for making API request . (GET , POST , PATCH , DELETE)
It works both in the browser and server side.
In React , we use mostly inside useEffect or event handlers.


fetch and axios :- 

1. fetch the data , we need to change mannuly in the json format.
2. axios , it automatically convert in the json format. -> store in the [data] variable

2. error handling is complex in fetch method.
3. Error handling is easy in axios.
