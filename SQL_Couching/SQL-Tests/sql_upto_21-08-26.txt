#SQL Classification

SQl is classified into the following categories.

DDL- Data Definition language 
DML - Data Manipulation Language
TCL - Transaction control language
DQL - Data Control Language
DCL- Data control Language


#DDL(used to define structure of the data in the database) :-
 Create(create a new obj(table,procedure,function,view), 
ALter, 
DROP, 
TRuncate

#DML(used to manage data within a database obj, it allows manipulation and querying the existing databse schema objs . the following table lists DML statements.:-
Insert(insert new data in a table),
UPdate(update existing records of table),
DElete(delete existing records in table).

#TCL(used to finalize the changes in the data made by executing the dml statements.:- 
Commit(permanently save transaction changes to the database),
rollback(restore database to its original state since the last commit.),
Savepoint(Create a SAvepoint to be later used by ROLLBACK Cmd to undo changes up to that point.)

#DQL(used to fetch data from the database.the main cmd is SELECT, which retrieves records based on the query) :- 
SELECT(used to retrieve data from the database)

#DCL(used to enforce database security by giving privileges to different users to access the database. :- 
Grant(Gives privilages to the user for accesssing data), 
Revoke(take back given privilages from the user).
